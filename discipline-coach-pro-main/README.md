# DisciAI – AI Powered Personal Discipline Tracking System

DisciAI is a web-based application designed to help users track daily habits and analyze their discipline patterns. The platform allows users to record activities such as study hours, workout time, sleep duration, and productivity tasks.

The system provides visual reports and insights that help users maintain discipline and improve their daily routines.

## Technologies Used

Frontend: React.js  
Language: TypeScript  
Framework: Vite  
Styling: Tailwind CSS  

## Features

- Add and manage daily habits
- Track weekly and monthly progress
- Generate discipline reports
- Simple dashboard interface

## Deployment

The project is deployed using Vercel.
